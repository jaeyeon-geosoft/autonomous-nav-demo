# SPEC — 선박 항적 데이터 뷰어

무엇을 만들지에 대한 상세 요구사항. 상시 맥락/스택/데이터 모델은 `CLAUDE.md` 참조.

## 목적

데이터 분석가가 준 항적 데이터를 지도 위에 재생하여, 그 데이터가
실제로 말이 되는 항적인지(위치가 튀지 않는지, 속도·침로가 자연스러운지)
눈으로 확인한다.

## 데이터 입력

- CSV 파일 로드(드래그앤드롭 또는 파일 선택). papaparse로 파싱.
- 파싱 결과를 컬럼 매핑 레이어를 통해 `TrackPoint[]`로 변환.
- timestamp 기준 오름차순 정렬. 유닉스 ms로 통일.
- 데이터가 없을 때는 `generateMockTrack()`으로 가짜 항적을 띄워
  바로 동작을 확인할 수 있게 한다.

### 컬럼 매핑

원본 헤더명 후보를 표준 필드에 매핑하는 테이블을 둔다. 예:

```
lat      ← lat, latitude, 위도, LAT
lon      ← lon, lng, longitude, 경도, LON
timestamp← timestamp, time, datetime, ts, utc
sog      ← sog, speed, speed_over_ground, 속력
cog      ← cog, course, course_over_ground
hdg      ← hdg, heading, true_heading, 선수방위
```

매핑에 실패한 필수 필드(timestamp/lat/lon)가 있으면 사용자에게
어떤 컬럼이 없는지 알려준다. (향후: UI에서 수동 매핑 지정)

## 화면 구성

한 화면에 아래를 배치(상단 지도 크게, 하단/우측에 컨트롤·정보):

1. **지도 (메인)**
2. **재생 컨트롤 바**
3. **현재 상태 정보 패널**
4. **데이터 품질 요약**

## 재생 엔진

- TrackPoint 배열과 "현재 재생 시각(커서)"을 상태로 관리.
- 재생 시 실제 timestamp 간격을 배속으로 나눠 진행.
  (예: 두 포인트가 10초 차이, 5배속이면 2초 후 다음 포인트)
- 포인트 사이는 선형 보간(lat/lon/heading)해서 마커가 부드럽게 이동.
- 컨트롤: 재생/일시정지, 배속(1x / 5x / 10x), 타임라인 스크러버
  (드래그로 임의 시점 점프), 처음으로 리셋.
- 현재 시각/전체 구간을 텍스트로도 표시.

## 지도 & 애니메이션

- Leaflet 베이스맵. `VITE_KHOA_KEY`가 있으면 KHOA 개방海 전자해도 WMS를 배경으로 쓰고,
  없으면 CARTO + OpenSeaMap seamark 오버레이로 폴백(설정은 `README.md` 참조).
    - seamark 타일 URL: `https://tiles.openseamap.org/seamark/{z}/{x}/{y}.png`
- 선박 마커: heading(없으면 cog, 그것도 없으면 진행 방향) 방향으로
  회전하는 삼각형/선박 아이콘. 재생에 따라 부드럽게 이동.
- 지나온 항적: 실제 지나온 경로를 polyline으로 그림.
- 전체 항적 미리보기 토글: 데이터 전체 경로를 옅게 깔아,
  튀는 구간을 한눈에 볼 수 있게.
- 첫 로드 시 항적 전체가 보이도록 지도 bounds 자동 맞춤(fitBounds).

## 현재 상태 정보 패널

현재 재생 시각 기준으로 표시(값 없으면 "—"):

- 위도 / 경도 (소수 5자리)
- SOG 대지속력 (knots, 1자리)
- HDG 선수방위 / COG 대지침로 (deg, 정수)
- 현재 timestamp (사람이 읽는 포맷)
- 진행률(전체 중 몇 %/몇 번째 포인트)

## 데이터 품질 검증

로드 시 전체를 스캔해서 이상 구간을 찾아 표시(개수 요약 + 지도에 하이라이트):

- **위치 점프**: 인접 포인트 간 거리/시간으로 계산한 속도가 비현실적으로
  큰 구간(예: 선박 최대 속도 초과 → 튀는 데이터 의심).
- **결측치**: 필수/주요 필드가 비어있는 포인트.
- **timestamp 이상**: 역전(이전보다 과거), 지나치게 큰 간격(장시간 공백).
- **범위 벗어남**: 위경도 범위 밖, 속도 음수, heading 0~360 밖 등.

각 이슈는 목록으로 보여주고, 클릭하면 해당 시점으로 재생 커서 이동.

## STR 데이터셋 대응 (구현 완료)

분석가가 준 STR 시뮬레이터 컬럼 사전 기준. 실 데이터는 아직 없음.

- `Time[s]` · `Latitude[deg]` · `GyroHeading[deg]` 같은 실제 컬럼명을 별칭 테이블에 추가.
- 다축(중앙 C / 좌현 P / 우현 S) 타·엔진 컬럼은 **C 우선, 없으면 P**를 대표값으로.
- 위험도(`Risk`) / 회피(`AvoidFlag`) / 사고(`Accident`)는 상태 패널 뱃지 + 이슈 목록에 표시.
- 해상 외란(바람·파도·조류)과 타/엔진 명령 vs 실제는 상태 패널에 **해당 컬럼이 있을 때만**
  섹션이 나타나게.

## 타선/예인선 (구현 완료)

`traffic_N` 테이블은 자선 데이터와 **별개 파일**이고, ID 컬럼으로 여러 척이 한 파일에 섞여 있다.

- 자선(`TrackPoint`)과 별도 모델(`TargetShip`)로 분리. 로드도 별도 버튼.
- 커서가 그 선박의 데이터 구간 밖이면 화면에서 **사라진다**(자선처럼 클램프하지 않음).
  시나리오 중간에 등장/퇴장하는 배를 그대로 표현하기 위함.
- 자선 항적을 새로 로드하면 이전 타선 데이터는 리셋(다른 시나리오이므로).

## 구현 순서 (1~7 완료)

1. ✅ TrackPoint 모델 + 컬럼 매핑 레이어 + `generateMockTrack()`
2. ✅ CSV 로드/파싱 → TrackPoint[] 변환
3. ✅ 재생 엔진(스토어: 커서, 재생상태, 배속) + 보간 로직
4. ✅ 지도 컴포넌트(베이스맵 + seamark, 마커 회전/이동, 항적 polyline, fitBounds)
5. ✅ 재생 컨트롤 바
6. ✅ 현재 상태 정보 패널
7. ✅ 데이터 품질 검증 + 이슈 목록/하이라이트

각 단계는 mock 데이터로 바로 눈으로 확인하면서 진행.
이후 진행 상황은 `docs/PROGRESS.md` 참조.
